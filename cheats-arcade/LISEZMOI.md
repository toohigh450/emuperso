# Cheats arcade (MAME 2003-Plus)

`cheat.dat` : base de codes de MAME 2003-Plus, 4 860 jeux d'arcade. Le lanceur le dépose dans le dossier
système du cœur au démarrage d'un jeu arcade ; MAME 2003-Plus n'en lit que les codes du jeu lancé et les
propose dans son menu (« Cheat », ouvert par le bouton « Ouvrir les cheats du jeu » ou le clic du stick
gauche). Aucun code n'est activé automatiquement.

- Source : `metadata/cheat.dat` du dépôt libretro/mame2003-plus-libretro, commit
  `7d3a3547e3e51081b0f71ad860962573dbc7e3f4` (27 octobre 2026), copie sans modification.
- Origine indiquée dans le fichier : « MAME CHEAT FILE Release Date: 21 APR 2004 (Base release for MAME
  0.81) », Pugsy's MAME Cheat Page (http://cheat.retrogames.com), adapté pour MAME 2003-Plus.
- SHA-256 : `67a0a8c6eebca04f9232ab39ee098c15866cc12e2ddeae28c105f282ddbde20e`.

Ce fichier ne contient que des adresses mémoire et des valeurs : aucun jeu, aucun BIOS.
