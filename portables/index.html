Portables 0.2.1 alpha

Game Boy, Game Boy Color, Game Boy Advance et DS dans Chrome. Un seul jeu à la fois.

Version alpha : exporte tes sauvegardes avant les essais. Jeux réels et lanceur Windows restent à valider.

La fente est vide

Choisis un fichier .gb, .gbc, .gba, .nds ou un .zip qui en contient un. Tes fichiers sont lus localement. Le moteur tiers chargé depuis Internet peut y accéder.

Tu peux aussi glisser le fichier sur la page.

    Chaque jeu a son propre espace de sauvegarde, identifié par l'empreinte du fichier et le cœur utilisé. Les sauvegardes du moteur restent dans ce navigateur. Une copie de sécurité (3 versions) est gardée en plus : elle ne remplace jamais la précédente sans la conserver.

    Jeux déjà ouverts

    Importe tes fichiers de codes au format .cht (par exemple le dossier « cht » de la base libretro). Les noms servent de suggestions. Confirme une association pour l’enregistrer pour cette ROM, même renommée. Une empreinte rom_sha256 déclarée dans le .cht permet aussi de l’identifier. Les nouveaux codes sont proposés désactivés ; le moteur peut mémoriser tes activations.
