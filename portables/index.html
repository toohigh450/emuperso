Version alpha : exporte tes sauvegardes avant les essais. Les tests réels et leurs limites sont dans TESTS-NES-SNES.md.

La fente est vide

Choisis un fichier .nes, .sfc, .smc, .gb, .gbc, .gba, .nds ou un .zip qui en contient un, ou un jeu PSP .iso, .cso ou .pbp. Tes fichiers sont lus localement et ne sont envoyés à aucun serveur. Le moteur tiers chargé depuis Internet peut y accéder.

Tu peux aussi glisser le fichier sur la page, ou ouvrir tout un dossier dans l’onglet Catalogue.

      Codes de ce jeu

      Les codes sont enregistrés pour ces octets précis de ROM (empreinte SHA-256) : une autre région ou un hack a sa propre liste. Le menu de codes du moteur est masqué : seul ce panneau décide, car plusieurs cœurs ignorent l’état « désactivé ».

      Fichiers de codes (.cht)

      Importe tes fichiers de codes au format .cht (par exemple le dossier « cht » de la base libretro). Les noms servent de suggestions. Confirme une association pour l’enregistrer pour cette ROM, même renommée. Une empreinte rom_sha256 déclarée dans le .cht permet aussi de l’identifier. Ses codes apparaissent ci-dessus, désactivés.

      Limites des codes : 2 Mio par fichier, 1000 fichiers / 32 Mio par lot, 5000 fichiers / 64 Mio au total. Une confirmation après modification vaut seulement pour cette ROM et ce contenu.

      Pour changer une touche ou un bouton de manette : icône manette dans la barre du jeu. Ce réglage est mémorisé par le moteur pour chaque jeu. Sur téléphone, les boutons tactiles apparaissent sous l’image (NES : A, B, Start, Select ; SNES : A, B, X, Y, L, R) ; leur disposition se règle dans le menu du jeu. Une manette Bluetooth reconnue par Chrome fonctionne aussi, à valider sur ton appareil.

      Cœurs : FCEUmm (NES, GPL-2.0), Snes9x (SNES, licence Snes9x non commerciale), Gambatte (GB/GBC), mGBA (GBA), DeSmuME / melonDS (DS). Compatibilité détaillée et limites : COMPATIBILITE-NES-SNES.md.

      ROM : plafond théorique 512 Mio, soumis au budget mémoire. Une ROM de 512 Mio est refusée si la mémoire déclarée est inconnue, 2 ou 4 Gio ; elle peut passer à 8 Gio sans jeu actif. Le budget ne mesure pas la RAM libre.
