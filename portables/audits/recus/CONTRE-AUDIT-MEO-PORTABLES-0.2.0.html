2. Corrections apportées (0.1 → 0.2.0)

🔑 Identité des ROMs (correction majeure)

Problème 0.1 : la sélection automatique des cheats reposait sur le nom de fichier, pas sur l'identité réelle du jeu. Critique pour les régions, révisions, traductions et hacks.

Correction 0.2.0 :

  • SHA-256 calculé sur tous les octets, même au-delà de 256 Mio
  • Le nom de fichier devient une suggestion à confirmer, pas une preuve
  • L'association manuelle conserve le SHA-256 complet, indépendamment du nom
  • Métadonnée facultative rom_sha256 pour correspondance automatique déclarée
  • Empreintes différentes ou mal formées → exclues

🎮 Cheats

  • Les codes nouvellement importés sont désactivés par défaut
  • Distinction claire entre import et activations que le moteur peut restaurer
  • Une empreinte ne prouve pas l'efficacité d'un code (honnêteté préservée)
  • Anciennes associations : confirmation à renouveler

📦 ZIP

  • Choix explicite du jeu dans les archives multi-jeux
  • Exclusion des métadonnées macOS (__MACOSX)
  • Refus : volumes multiples, offsets, répertoires tronqués, taille annoncée excessive
  • CRC32 toujours contrôlé
  • ZIP64, chiffrés, RAR, 7z → exclus (documenté)

💾 Chargement et stockage

  • Parcours de chargement sérialisé, boutons désactivés pendant l'ouverture
  • Échec de chargement → le jeu précédent reste intact
  • Vérification effective de l'ouverture IndexedDB, avec repli averti
  • Mises à jour des miroirs sérialisées par jeu
  • Les nouveaux jeux utilisent le SHA-256 complet comme nom interne
  • Anciens noms conservés pour retrouver les sauvegardes (sans migration destructive)

🔧 Moteur

  • Retrait du secours @latest — pouvait mélanger une branche de développement avec une distribution stable
  • Source locale puis CDN stable
  • Cœurs confirmés : Gambatte, mGBA, DeSmuME, DeSmuME 2015, melonDS

4. Limites honnêtes (déclarées)

  • Les mises à jour simultanées ne constituent pas une garantie d'atomicité en cas de panne ou de quota
  • Le serveur Windows n'a pas été exécuté dans cet environnement
  • Les binaires des cœurs ne sont ni embarqués ni verrouillés à une version précise
  • Aucune base de cheats embarquée, aucune ROM commerciale
  • Limites de mémoire, de compatibilité et de mise à jour explicites dans la doc
