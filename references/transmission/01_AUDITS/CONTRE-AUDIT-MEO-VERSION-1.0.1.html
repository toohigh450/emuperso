3. Le correctif 1.0.1 — vérifié dans le code, pas seulement annoncé

Problème circonscrit (et honnêtement borné par Codex lui-même) : dans src/ui.mjs, chaque render(v) lance instance.journal.export() de façon asynchrone. Sans garde d'ordre, une réponse ancienne pouvait théoriquement écrire dans le DOM après une réponse plus récente. Aucune inversion spontanée en 1.0.0 n'est démontrée : les tests injectent artificiellement l'inversion. Le correctif ne prétend pas réparer un bogue observé, il ferme une course théorique.

Implémentation lue par Méo :

  • src/latest-result.mjs (337 octets, nouveau en 1.0.1) : createLatestResultGate() ; issue() crée un Symbol('render') neuf, le mémorise et retourne un prédicat current === ticket ; invalidate() annule le ticket courant. Les Symboles évitent toute collision d'identifiant.
  • src/ui.mjs : createLab() appelle journalRenderGate.invalidate() ; render(v) capture simultanément l'instance (const instance = laboratory) et le ticket (isCurrentRender = journalRenderGate.issue()) avant l'export ; le callback de succès vérifie les deux conditions (laboratory !== instance || !isCurrentRender() → abandon) avant d'écrire dans le DOM ; le catch vérifie les mêmes deux conditions avant d'afficher une erreur.
  • Le journal, les événements, leurs chaînes SHA-256, le stockage et l'adaptateur synthétique ne sont pas modifiés par cette barrière — confirmé par la comparaison §5 : journal.mjs est octet pour octet identique à la 1.0.0.

Comportement résiduel explicitement accepté (à ne pas mal interpréter) : si l'export courant échoue, les dernières lignes du journal précédemment affichées restent à l'écran et un message d'erreur apparaît. Ce n'est pas une corruption du journal, mais les lignes visibles ne doivent pas être lues comme une actualisation réussie après l'erreur. La barrière n'interrompt pas physiquement l'export en cours : elle ignore sa réponse devenue périmée. De même, les champs synchrones de render(v) (état, identités, métriques) ne sont pas filtrés par la barrière — c'est la section journal asynchrone qui l'est, et c'est bien là que se situait la course.
