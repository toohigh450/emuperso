La démo de référence utilise un boot pour émulateur avec 8 Mio de RAM. Les imports conservent leur propre code de démarrage ; seul l’ordre des octets est normalisé. Ce chantier est séparé du N64 Web Lab synthétique. Les fichiers du Lab, Conker et TN-1 restent intacts.

Import local uniquement : .z64, .n64 ou .v64 extrait, de 4 Kio à 64 Mio. Aucun envoi de votre fichier au serveur. Après un lancement, rechargez la page pour changer de ROM. Reconnaître un format ne garantit pas qu’un jeu fonctionne.
