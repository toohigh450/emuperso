N64 Web 0.3.0 — importer directement un ZIP

31 octobre 2026 · branche emulateur-reel. Mise à jour du prototype réel uniquement. Aucun fichier Conker, TN-1, du laboratoire synthétique ou de main modifié.

DEMARRER-N64 → Choisir une ROM → sélectionner un .zip. Une ROM : extraction automatique. Plusieurs ROM : choix explicite puis Préparer cette ROM. Terminer avec Lancer la ROM choisie. La démo MIT et les imports .z64/.n64/.v64 restent disponibles.

Implémenté

Le ZIP est lu dans le navigateur. Son répertoire et ses en-têtes sont inspectés avant extraction. Seule la ROM choisie est décompressée, son CRC-32 est vérifié, puis taille, signature et ordre des octets passent par le validateur existant. Les empreintes SHA-256 de l’archive, de la ROM source et de sa version Z64 sont distinguées. Le moteur reçoit une URL Blob et un identifiant fondé sur le contenu ; aucun nom d’entrée ne devient un chemin serveur.

Le module ZIP est original, sans bibliothèque tierce ajoutée. Stockage utilise une copie locale ; Deflate utilise le décompresseur natif du navigateur. Aucune écriture de fichiers extraits, aucun upload ni appel externe dans les parcours testés. Un nouveau choix ou un lancement de référence invalide les opérations précédentes ; la décompression active reçoit un signal d’annulation.

Garde-fous et limites

LimiteValeur
ArchiveZIP32 standard, 96 Mio maximum, 512 entrées, répertoire central ≤ 2 Mio
ROM4 Kio à 64 Mio inclus, taille multiple de quatre
Contenu déclaré total256 Mio maximum ; seule la ROM choisie est extraite
CompressionStockage (0), Deflate (8) ; Chrome récent avec DecompressionStream deflate-raw
Refus explicitesZIP64, mots de passe/chiffrement, multivolume, autres méthodes, fichiers spéciaux/liens, chemins dangereux, doublons, chevauchements et incohérences d’en-têtes/descripteurs

La sortie est bornée pendant la lecture Deflate ; une taille déclarée mensongère n’est pas acceptée. CRC détecte une corruption, pas l’authenticité ou l’innocuité d’une ROM. Ni CRC ni SHA ne prouvent qu’un jeu est compatible. Les scripts et fichiers annexes ne sont jamais exécutés.

Archives imbriquées et auto-extractibles non prises en charge. Les anciens noms non UTF-8 peuvent afficher des caractères approximatifs. Après l’échec d’une entrée choisie, resélectionner le ZIP pour choisir à nouveau. Le diagnostic exporté volontairement contient des noms et empreintes, jamais les octets des ROM ou du ZIP.

Livraison et décision

Lancement Windows simplifié conservé, aucun Python système requis. Internet nécessaire au premier démarrage pour les dépendances officielles figées. Sources et notices dans le dépôt ; SHA-256 dans MANIFEST-SHA256.txt. Le ZIP de livraison exclut les caches, Python portable installé et les binaires du moteur ; leur préparation est automatique et leurs licences restent conservées.
