Correctifs implémentés

PointComportement
C01 — changement de varianteLe choix d’une autre variante est bloqué tant qu’un code est actif. La sélection précédente et les codes actifs restent visibles. Les codes d’une partie restaurée restent accessibles même si l’édition du catalogue est ambiguë.
C02 — échec partiel du moteurLa liste entière est validée avant reset. Une exception native marque le contexte indéterminé, bloque ses captures et sa reprise, puis le contrôleur le retire. Une relance explicite crée un moteur neuf sans codes actifs à partir du natif déjà conservé, sans capturer la mémoire incertaine.
C03 — valeurs HTMLLes identifiants numériques reçus comme texte depuis le sélecteur correspondent désormais aux identifiants du catalogue ; les valeurs non canoniques sont refusées.
C04 — choix d’état pendant une sauvegardeLe fichier choisi est retenu pendant une écriture native, avec attente bornée à30s. Un changement de partie annule explicitement l’import ; les contrôles d’identité et de SHA restent actifs.

Le cœur figé ne fournit pas de lecture certifiée de sa liste native. Aucun rollback natif n’est prétendu vérifié. Une désactivation réussie arrête les écritures futures sans annuler leurs effets déjà présents. Une native conservée peut contenir des effets antérieurs.
