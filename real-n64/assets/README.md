# Décor de l’interface

`goku-vegeta-fusions.png` est une illustration générée pour Karl le 31 octobre
2026, à sa demande : Goku, Vegeta, Gogeta, Vegito et Veku, sous plusieurs formes.
Les personnages appartiennent à leurs ayants droit ; ils ne sont pas des personnages
originaux du projet. La licence MIT du code ne constitue pas une licence sur ces personnages.

L’image est servie localement, sans CDN. Elle reste décorative : arrière-plan sans
événement de souris et bannière complète en `object-fit: contain`, sans recouvrir
le jeu ou les boutons. Aucun texte ni logo n’est incorporé dans l’illustration.
