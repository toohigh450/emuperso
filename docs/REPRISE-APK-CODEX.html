EMUPERSO.apk : audit et reprise sur ordinateur

3 novembre 2026. Mission : issue #7. APK non construit ; aucune installation Android vérifiée.

Constats vérifiés par GitHub

  • La branche PWA est au commit c917ce711ecbe358952d0c3508cc1540eb3538db lors de l'audit.
  • La comparaison vers feature/unified-controller-profiles indique 28 commits d'avance et 3 de retard. Cette comparaison n'est pas une validation fonctionnelle des 28 commits.
  • portail/ ne contient que index.html, manifest.webmanifest et sw.js : les trois icônes PNG manquent. Leur copie obligatoire fait échouer la construction du portail.
  • Le build de la branche manettes ne copie pas les ressources PWA ; celui de la branche PWA ajoute cette copie. L'intégration doit préserver le portail et les moteurs récents.
  • Le service worker v1 met en cache tous les GET de même origine et supprime aussi les caches d'autres applications. Cela dépasse l'enveloppe prévue par le mandat.

Correctif proposé

Le service worker v2 limite le cache à cinq URL exactes : /, le manifeste et les trois icônes. Il utilise le réseau en priorité et une copie locale en cas de panne réseau. Les routes des moteurs, jeux, BIOS et sauvegardes ne sont pas interceptées. Il retire les anciens caches emuperso-sw-* et préserve les autres caches. Les erreurs HTTP et redirections ne remplacent pas une bonne copie. Les écritures en cache sont attendues ; un dépassement de quota ne bloque pas la réponse réseau.

Sept tests automatisés réussis dans une simulation Node du service worker : installation, nettoyage des caches, absence d'interception des autres ressources, mise à jour réseau, repli hors ligne, erreurs HTTP/redirections et quota. Commande : node tests/pwa-service-worker.test.mjs. Ces tests ne remplacent pas Chrome Android ni une validation TWA.

Limites de cet environnement

Le connecteur GitHub fonctionne. Les commandes git clone et curl échouent avec « Failed to connect to proxy port 8080 ». Node 24 et Java 21 sont disponibles, mais adb, sdkmanager et gradle ne sont pas dans le PATH. Aucun appareil Android n'est connecté. Les icônes originales indiquées dans le mandat ne sont pas disponibles dans cet espace de travail. Aucun keystore n'a été créé.
