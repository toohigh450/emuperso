EMUPERSO Controller V2

Rapport d’étape, 2 novembre 2026 · branche feature/unified-controller-profiles · aperçu Vercel, pas de production.

En bref

  • Fait : deux profils (Authentique, Confort moderne) et un mode Natif pour les 8 consoles du lanceur et la N64 ; manette lue par EMUPERSO, sans double commande ; commandes tactiles PSP ✕ ○ □ △ avec stick ; commandes tactiles cachées quand une manette est branchée ; réglages par console ou par jeu ; codes chargés automatiquement à l’ouverture d’un jeu.
  • Pas encore fait : déplacement des boutons tactiles au doigt ; PS1 laissée telle quelle (déjà deux profils) ; essais sur vraie manette Xbox et sur le OnePlus 10T (Karl).

Non vérifié — à faire par Karl

  • Vraie manette Xbox sur Chrome Windows, puis en Bluetooth sur le OnePlus 10T (Chrome Android n’expose pas toujours tous les boutons, dont le bouton Xbox).
  • Confort tactile sur le vrai téléphone, portrait et paysage, plusieurs doigts ; écran tactile DS ; boutons C tactiles N64 ; stick tactile PSP.
  • Effet réel des codes en jeu.

Limites connues

  • Boutons tactiles : taille et opacité réglables, mais pas encore déplaçables au doigt.
  • PSP sur le moteur nightly : charger un état et redémarrer figent le jeu ; ces actions sont bloquées par le lanceur.
  • Genesis : la collection est en .7z, que le navigateur n’ouvre pas ; extraire la version voulue avant de l’ouvrir.
  • Codes automatiques : proposés par identifiant de disque (PSP) ou par titre ; l’association reste à confirmer d’un clic, aucun code n’est activé.

Aucune ROM, aucun BIOS ni aucune sauvegarde dans le dépôt ou sur Vercel. Aucune fusion dans main sans l’accord de Karl.
