Sauvegardes

La carte mémoire est celle produite par le jeu ; un save state est une photo complète de la partie. Séparés, et liés à l’identité du disque, du moteur et de sa configuration : jamais mélangés entre jeux.

Choisissez un jeu pour consulter ses états.

Les sauvegardes sont stockées dans ce navigateur, sur ce PC. L’effacement des données du navigateur les supprime. Le chargement d’un état redémarre une session neuve, puis restaure l’état.

Manette

Aucun jeu chargé.

Disposition positionnelle Xbox 360 : A (bas) = Croix, B (droite) = Rond, X (gauche) = Carré, Y (haut) = Triangle. La croix physique reste toujours active. Le mode analogique est à réserver aux jeux qui le gèrent : certains jeux ne répondent plus aux commandes dans ce mode. Un changement de type de manette redémarre le jeu ; les états sont séparés par type de manette, la carte mémoire non.
