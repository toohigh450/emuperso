Bon à savoir

Tes jeux restent chez toi

Le site ne peut pas lire ton disque : tu choisis toi-même un fichier ou un dossier. Rien n’est envoyé à un serveur ; le jeu tourne dans ton navigateur. Aucun jeu commercial ni BIOS n’est fourni.

Sauvegardes séparées

Chaque jeu a son propre espace, identifié par l’empreinte de son fichier. Le navigateur peut effacer ces données (nettoyage, manque de place) : exporte régulièrement tes sauvegardes.

Téléphone Android

Les boutons tactiles apparaissent sous l’image. Le son démarre après un premier toucher. Une manette Bluetooth reconnue par Chrome fonctionne aussi.
