Nouveautés

    Application Android (test)

    EMUPERSO en application : elle ouvre ce même site en plein écran, sans barre Chrome. Android 7 ou plus, Chrome à jour. Version de test : son installation reste à confirmer sur ton téléphone.

    1. Télécharge le fichier depuis ton téléphone Android.
    2. Ouvre-le. Si Android le demande, autorise pour cette fois l’installation depuis l’application qui l’ouvre.
    3. Installe, puis retire cette autorisation. Aucun jeu ni BIOS n’est inclus : tes jeux restent sur ton appareil.
    Télécharger EMUPERSO.apk (2,5 Mo)

    Empreinte SHA-256 du fichier : e0b42c20567eb15c133ae2bc36b8491f48c45ded906fd6bc6772b95ea0fce8c5

    Bon à savoir

    Tes jeux restent chez toi

    Le site ne peut pas lire ton disque : tu choisis toi-même un fichier ou un dossier. Rien n’est envoyé à un serveur ; le jeu tourne dans ton navigateur. Aucun jeu commercial ni BIOS n’est fourni.

    Sauvegardes séparées

    Chaque jeu a son propre espace, identifié par l’empreinte de son fichier. Le navigateur peut effacer ces données (nettoyage, manque de place) : exporte régulièrement tes sauvegardes.

    Téléphone Android

    Les boutons tactiles apparaissent sous l’image. Le son démarre après un premier toucher. Une manette Bluetooth reconnue par Chrome fonctionne aussi.
