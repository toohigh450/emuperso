Limites connues — version ALPHA

  • WebGPU requis : Chrome/Edge récent, Safari 26+ ou Chromium avec WebGPU. Sans WebGPU, rien ne démarre.
  • Interprété, sans audio : pas de JIT Cranelift dans le navigateur ; les images disque observées tournaient autour de 16–23 % de la vitesse native sur la machine de test — beaucoup de jeux commerciaux seront trop lents ou injouables.
  • Boots prouvés uniquement : le moteur démarre des images disque, mais la jouabilité complète n’est pas validée. Traite cette version comme un banc d’essai.
  • Un seul boot par session : pas de redémarrage à chaud ni d’états de sauvegarde (sérialisation absente du moteur web).
  • Carte mémoire 2 Mio : sauvegardes par jeu dans le navigateur ; export/import .mcr possible. La carte n’est pas relue à chaud : importe-la avant de lancer.
  • Moteur : Gecko (ioncodes/gecko, GPL-3.0) compilé WebAssembly — voir gamecube/SOURCE.md pour la provenance exacte.
